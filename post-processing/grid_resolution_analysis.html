Grid resolution analysis¶

In a wall-resolved LES or DNS, the grid next to the wall must be fine enough to resolve the near-wall turbulent structures. Whether it is fine enough is judged in wall units, i.e. relative to the viscous length scale of the boundary layer. This notebook defines the three standard metrics, $y^+$, $\Delta x^+$ and $\Delta z^+$, and evaluates them on the surface of an airfoil from a time-averaged m-AIA solution.

1. Wall units¶

The wall shear stress $\tau_w$ defines the friction velocity $u_\tau$ and the viscous length scale $\ell_\nu$:

$$ u_\tau = \sqrt{\frac{\tau_w}{\rho_w}}, \qquad \ell_\nu = \frac{\nu_w}{u_\tau}, \qquad \nu_w = \frac{\mu_w}{\rho_w}. $$

A length expressed in wall units is that length divided by $\ell_\nu$. The grid resolution metrics are the wall-adjacent grid spacings in wall units:

$$ y^+ = \frac{y_1\,u_\tau}{\nu_w}, \qquad \Delta x^+ = \frac{\Delta x\,u_\tau}{\nu_w}, \qquad \Delta z^+ = \frac{\Delta z\,u_\tau}{\nu_w}, $$

where $y_1$ is the wall distance of the first cell centre, and $\Delta x$ and $\Delta z$ are the streamwise and spanwise cell sizes at the wall. Here $y^+$ refers to the first cell centre; some guidelines use the first cell height instead, which is twice as large.

Wall shear stress from the first cell¶

The wall shear stress is estimated from the velocity at the first cell centre, assuming a linear profile between the wall (no slip) and that point:

$$ \tau_w = \mu_w \left.\frac{\partial u_t}{\partial n}\right|_w \approx \mu_w\,\frac{u_{t,1}}{y_1}, $$

where $u_{t,1}$ is the wall-tangential velocity at the first cell centre. Because $y^+ \lesssim 1$ places the first cell inside the viscous sublayer, where $u^+ = y^+$, this estimate is consistent with the resolution it is used to check.

The viscosity follows Sutherland's law, $\mu \propto T^{3/2}/(T + S)$. In the non-dimensional solver variables, the viscous terms carry a factor $1/Re_0$, with $Re_0$ the Reynolds number per unit reference length.

Typical targets¶

$y^+$ $\Delta x^+$ $\Delta z^+$
Wall-resolved LES $< 1$ $50 - 150$ $15 - 40$
DNS $< 1$ $10 - 15$ $5$

Values after Georgiadis, Rizzetta & Fureby, AIAA J. 48(8), 2010.

Where $\tau_w \to 0$, i.e. at the stagnation point and at separation or reattachment points, $u_\tau \to 0$ and all three metrics drop towards zero. These dips do not indicate a fine grid; the resolution should be judged on the attached parts of the boundary layer.

2. Data¶

The grid and solution are m-AIA HDF5 files. Only the wall-adjacent layers are needed: the first two node layers of the grid ($j = 0, 1$) and the first cell layer of the solution. The block is an O-grid around the airfoil, with $i$ running around the surface, $j$ normal to the wall and $k$ in the spanwise direction. Datasets are stored as [k, j, i].

The files used here contain only those layers, extracted from a full grid and time-averaged solution. The code reads the same slices from full-size files, so it can be pointed at them directly.

import h5py
import numpy as np
import matplotlib.pyplot as plt

GRID_FILE = "../data/grid_wall.hdf5"
SOL_FILE  = "../data/solution_wall.hdf5"
BLOCK     = "block0"

GAMMA = 1.4        # ratio of specific heats
S     = 110.4      # Sutherland constant [K]
T_REF = 273.15     # reference temperature [K]

def read(group, name):
    # Instantaneous files store u, v, ...; time-averaged files store um, vm, ...
    return group[name] if name in group else group[name + "m"]

with h5py.File(GRID_FILE, "r") as fg, h5py.File(SOL_FILE, "r") as fs:
    x, y, z = (fg[BLOCK][c][:, 0:2, :] for c in "xyz")       # node layers j = 0, 1
    u, v, w, rho, p = (read(fs[BLOCK], n)[:, 0, :] for n in ("u", "v", "w", "rho", "p"))
    ma, re = float(np.squeeze(fs.attrs["Ma"])), float(np.squeeze(fs.attrs["Re"]))

print(f"Grid nodes (k, i): {x[:, 0, :].shape},  wall cells (k, i): {u.shape}")

3. Grid spacings at the wall¶

  • $y_1$: distance from the wall face centre to the first cell centre. The same vector, normalised, gives the wall normal $\hat{\mathbf n}$.
  • $\Delta x$: length of the wall cell edges along $i$, averaged over the two edges of each cell.
  • $\Delta z$: the same along $k$.
In [2]:
def face_centres(a):
    # Node values (k, i) -> face-centre values (k-1, i-1)
    return 0.25*(a[:-1, :-1] + a[1:, :-1] + a[:-1, 1:] + a[1:, 1:])

wall_nodes = np.stack([c[:, 0, :] for c in (x, y, z)])            # (3, nk, ni)
wall_face  = np.stack([face_centres(c[:, 0, :]) for c in (x, y, z)])
top_face   = np.stack([face_centres(c[:, 1, :]) for c in (x, y, z)])
centre     = 0.5*(wall_face + top_face)                            # first cell centres

d  = centre - wall_face
y1 = np.linalg.norm(d, axis=0)                                     # wall distance
n  = d/y1                                                          # unit wall normal

dx = np.linalg.norm(np.diff(wall_nodes, axis=2), axis=0)          # edges along i
dx = 0.5*(dx[:-1, :] + dx[1:, :])
dz = np.linalg.norm(np.diff(wall_nodes, axis=1), axis=0)          # edges along k
dz = 0.5*(dz[:, :-1] + dz[:, 1:])

4. Friction velocity and wall units¶

The freestream state follows from the Mach number, with the solver's non-dimensionalisation by stagnation quantities. It gives $Re_0$, which converts the non-dimensional viscosity into the effective one. The local temperature is $T = \gamma p/\rho$.

In [3]:
def sutherland(T):
    return T**1.5*(1 + S/T_REF)/(T + S/T_REF)

t_inf   = 1.0/(1.0 + 0.5*(GAMMA - 1.0)*ma**2)
u_inf   = ma*np.sqrt(t_inf)
rho_inf = t_inf**(1.0/(GAMMA - 1.0))
re0     = re*sutherland(t_inf)/(rho_inf*u_inf)      # Reynolds number per unit length

T  = GAMMA*p/rho
mu = sutherland(T)
nu = mu/rho

vel  = np.stack([u, v, w])
u_t  = np.linalg.norm(vel - np.sum(vel*n, axis=0)*n, axis=0)   # wall-tangential velocity
tau  = mu/re0*u_t/y1
utau = np.sqrt(tau/rho)

inv_lnu = utau*re0/nu                                # 1/ℓν
metrics = {r"$y^+$": y1*inv_lnu, r"$\Delta x^+$": dx*inv_lnu, r"$\Delta z^+$": dz*inv_lnu}

5. Suction and pressure side¶

The surface is split at the leading edge (minimum $x$). The suction side is the one with the lower mean pressure. For each surface position, the spanwise mean and the spanwise minimum and maximum are computed.

xc = centre[0].mean(axis=0)
i_le = np.argmin(xc)
sides = {"a": np.arange(0, i_le + 1), "b": np.arange(i_le, len(xc))}
if p[:, sides["a"]].mean() < p[:, sides["b"]].mean():
    sides = {"suction": sides["a"], "pressure": sides["b"]}
else:
    sides = {"suction": sides["b"], "pressure": sides["a"]}

def surface_stats(idx):
    idx = idx[np.argsort(xc[idx])]
    return xc[idx], {k: (m.mean(axis=0)[idx], m.min(axis=0)[idx], m.max(axis=0)[idx])
                     for k, m in metrics.items()}

def plot_sides(x_max=0.9):
    fig, axs = plt.subplots(3, 2, figsize=(12, 8), sharex=True, sharey="row")
    for col, (name, color) in enumerate((("suction", "tab:red"), ("pressure", "tab:blue"))):
        xs, stats = surface_stats(sides[name])
        keep = xs <= x_max
        for ax, (label, (mean, lo, hi)) in zip(axs[:, col], stats.items()):
            ax.fill_between(xs[keep], lo[keep], hi[keep], color=color, alpha=0.2, lw=0, label="spanwise min–max")
            ax.plot(xs[keep], mean[keep], color=color, lw=1.5, label="spanwise mean")
            ax.set_ylim(bottom=0)
            ax.grid(alpha=0.3)
            if col == 0:
                ax.set_ylabel(label)
        axs[0, col].axhline(1.0, color="k", ls="--", lw=1, label="$y^+ = 1$")
        axs[0, col].legend(loc="upper right", fontsize=8)
        axs[0, col].set_title(f"{name.capitalize()} side")
        axs[-1, col].set_xlabel("$x/c$")
    axs[-1, 0].set_xlim(0, x_max)
    fig.tight_layout()
    plt.show()
